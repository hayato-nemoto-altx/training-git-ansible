# よくあるエラーと対処法

シフトの合間に進めていると、ふと手が止まるトラブルが起きるものです。焦らずここを確認してください。

## Q1. 「PullしちゃいけないところでPullしちゃった！」
- **症状：** 古い状態から始めるついでに、うっかり `main` をPullして最新にしちゃった。
- **対処：** 一度そのステップのブランチを削除し、もう一度古い `main` からブランチを切り直せば大丈夫です。やり直す勇気が一番の近道！

## Q2. Ansibleの実行で「インデント（空白）エラー」が出る
- **症状：** `AnsibleError: syntax error` や `Line contains tab characters` と怒られる。
- **対処：** YAMLファイルでは **TABキーのインデントが厳禁** です。必ず「半角スペース2つ（または4つ）」でインデントを揃えてください。

## Q3. SourceTreeで「認証エラー（Authentication failed）」が出る
- **症状：** プッシュやプルをしようとするとパスワードやトークンを求められて弾かれる。
- **対処：** GitHubの仕様変更により、通常のパスワードではなく「Personal Access Token（アクセストークン）」を発行してパスワード欄に入力する必要があります。先輩にやり方を聞くか、GitHubの設定画面からトークンを再発行しましょう。

困ったときは、エラー画面のスクショを撮って、いつでもチャットで先輩を呼んでね！
