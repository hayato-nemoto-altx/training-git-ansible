## 🎉 Step 10. 完成：Ansible実行とWebページの確認
1. **最新状態を集める：**
   - SourceTreeで `main` ブランチに切り替えます。
   - **「Pull」** ボタンを押して、GitHubにある最新の全ファイルをローカルに引っ張ってきます。
   
> [!TIP]
> **ターミナル（CLI）で行う場合**
> ```bash
> git checkout main
> git pull origin main
> ```

2. **ファイルが揃っているか確認する：**
   - フォルダの中に、Aさんが作った `group_vars/all.yml` と、Bさんが書き換えた新しい `site.yml` の両方が綺麗に揃っていることを確認します。
3. **Ansibleを走らせる！**
   - VS Codeの統合ターミナル（Windowsの方はWSL接続中のターミナル）を開き、以下のコマンドをビシッと打ち込みます。
   ```bash
   ansible-playbook site.yml
   ```
   - 画面に「PLAY [ローカルWebページの生成] ...」といった文字が流れ、最後に **「changed=1」** などの緑文字が表示されたら大成功です！
4. **ブラウザで確認する：**
   - パソコンのフォルダ内を見てみると、なんと `index.html` というファイルがシュッと新しく自動生成されています。
   - このファイルをダブルクリックしてブラウザ（Chromeなど）で開いてみてください。
   - **「このページは インフラ構築チーム が自動生成しました。」** と表示されていれば、これにて全カリキュラム修了です！
