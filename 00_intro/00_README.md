# 研修の目的と進め方

ようこそ！この研修では、シフトのスキマ時間を活用して、これからの開発やインフラ作業に欠かせない**「バージョン管理（Git/GitHub/SourceTree）」**と**「自動化（Ansible）」**の基礎を叩き込みます。

## この研修のゴール
- **Gitの基本動作**（コミット、プッシュ、プル）を体で覚える。
- **チーム開発の落とし穴**である「コンフリクト（競合）」をあえて体験し、その解決方法を身につける。
- **Ansible**を使って、設定ファイルからWebページを自動生成する流れを知る。

## ⏱️ 進め方のルール
- 1コマ **20〜30分程度** で区切れるように作られています。
- シフトの合間や、自分の仕事のキリが良いタイミングでコツコツ進めてOKです。
- 前半（Step 1〜5）でコンフリクトについて理解し、後半（Step 6〜10）でコンフリクトを防ぐ仕組みを体験します。

焦らず、自分のペースでしっかりと手を動かしていきましょう！
