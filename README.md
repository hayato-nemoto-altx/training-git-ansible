# Git × SourceTree × Ansible 実践演習

ようこそ！この演習では、スキマ時間を活用して「バージョン管理（Git）」と「自動化（Ansible）」の基礎を自分の手で学びます。

## 演習の進め方
- 1コマ **20〜30分程度** で、自分のペースで進めてください。
- 前半（Step 1〜5）でコンフリクトについて理解し、後半（Step 6〜10）でコンフリクトを防ぐ仕組みを体験します。
- 前後半を通してgitとansibleに触れることで基礎を理解する試みです
